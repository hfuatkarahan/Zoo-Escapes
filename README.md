<h1 align="center"> 🦊 Zoo Escapes </h1>
<p align="center"> 🏆 This game includes the adventures of cute animals trying to escape from the zoo despite the obstacles. It is an interpretation of popular game Subway Surfer. </p>

## 🕹️ Setup
You can play the game from this link ➡️ https://hfkarahan.itch.io/zoo-escapes or just run the "index.html" file in the "Build" folder. </br>

📱 The game is compatible with Android. Touch feature is active.

## 🎮 Controls
<kbd> A </kbd>  Left or ⬅️ Swipe </br>
<kbd> D </kbd>  Right or ➡️ Swipe </br>
<kbd> W </kbd>  Jump or ⬆️ Swipe </br>
<kbd> S </kbd>  Somersault or to land in the air or ⬇️ Swipe


## 📖 Features
🚧  2 types of obstacles - barricade and train </br>
🚀 4 types of powerups - magnet, shield, super jump and score boosting star </br>
🚋 Train kills the player </br>
❌ If you don't have a shield and hit an obstacle it's game over </br>
⭐ Each star increases the score multiplier by one
